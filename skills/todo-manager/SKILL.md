---
name: todo-manager
description: Manage local tasks and import externally tracked tasks without duplicates.
---

Use todo_list and todo_get to inspect current work. Create tasks only when requested or authorized by the current workflow. Update using the current revision to avoid overwriting concurrent changes. Distinguish todo, doing, blocked, done, and cancelled. Imported tasks retain their external source identity. Local changes do not imply permission to update remote systems.

A request to do work does not by itself authorize creating a saved task.
